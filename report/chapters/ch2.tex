\subsubsection{Introduction}
 Grace au générateurs, nous pouvons addtionner nos matrices sans utiliser la formule standart.
 En effet, selon la propriété 10.7 et 10.8 du cours (ref cours ICI), on apprends que la somme de 2 matrices toeplitz peut etre simplfié par la concatenation de leurs générateurs de déplacement.
 Cela permet de passer a un coup de O($n \times m$) a un cout de O($\alpha \times m$) pour 2 matrices A et B de tailles $n \times m$ et leurs générateurs de taille $\alpha$ pour ceux de A et $\beta$ pour ceux de B.
 Avec flint, on peut utiliser la fonction
 \begin{verbatim}
 int gr_mat_concat_horizontal(gr_mat_t RES,gr_mat_t A,gr_mat_t B,gr_ctx_t ctx);
 \end{verbatim}
 pour faire la concatenation de nos générateurs.

\subsubsection{Introduction}
Toujours avec les générateurs, on peut simplifier la multiplication de 2 matrices et donc réduire son cout en concatenant :

- les générateurs de A=(T,U) et B=(G,H)


- $W = Z \times A \times Z^t \times G$

- $V = B^t \times U$

- a (resp. b) un vecteur qui est la dernière colonne de$ Z \times A $ (resp. $Z^t \times B$)

Cela nous permet de passer de O($n^3$) pour l'algo naif a $O( \alpha^2 \times M(n) )$ pour la version que nous implémentons.

\subsubsection{Multiplication Vecteur/Générateur}
Pour faire notre multiplication de matrice vie leurs générateurs, nous avons besoin d'avoir une fonction qui va multiplier un vecteur avec des générateurs pour éviter  de recomposer les matrices.
\begin{verbatim}
 int gr_mat_mul_vector(gr_mat_t Res, gr_mat_t G, gr_mat_t H, gr_mat_t X, gr_ctx_t ctx) {
  int error = GR_SUCCESS;
  slong n = gr_mat_nrows(G, ctx), m = gr_mat_nrows(H, ctx);
  slong alpha = gr_mat_ncols(G, ctx), m_cols = gr_mat_ncols(X, ctx);

  gr_poly_t pg, ph, px, p_tmp;
  gr_poly_init(pg, ctx);
  gr_poly_init(ph, ctx);
  gr_poly_init(px, ctx);
  gr_poly_init(p_tmp, ctx);

  error = gr_mat_zero(Res, ctx);
  if (error) {
    gr_poly_clear(pg, ctx);
    gr_poly_clear(ph, ctx);
    gr_poly_clear(px, ctx);
    gr_poly_clear(p_tmp, ctx);
  }

  for (slong j = 0; j < m_cols; j++) {
    gr_poly_fit_length(px, m, ctx);
    for (slong r = 0; r < m; r++) {
      error = gr_set(gr_poly_coeff_ptr(px, r, ctx), gr_mat_entry_srcptr(X, r, j, ctx), ctx);
      if (error) {
        gr_poly_clear(pg, ctx);
        gr_poly_clear(ph, ctx);
        gr_poly_clear(px, ctx);
        gr_poly_clear(p_tmp, ctx);
      }
    }
    _gr_poly_set_length(px, m, ctx);

    for (slong k = 0; k < alpha; k++) {
      gr_poly_fit_length(pg, n, ctx);
      for (slong r = 0; r < n; r++) {
        error = gr_set(gr_poly_coeff_ptr(pg, r, ctx), gr_mat_entry_srcptr(G, r, k, ctx), ctx);
        if (error) {
          gr_poly_clear(pg, ctx);
          gr_poly_clear(ph, ctx);
          gr_poly_clear(px, ctx);
          gr_poly_clear(p_tmp, ctx);
        }
      }
      _gr_poly_set_length(pg, n, ctx);

      gr_poly_fit_length(ph, m, ctx);
      for (slong r = 0; r < m; r++) {
        error = gr_set(gr_poly_coeff_ptr(ph, r, ctx), gr_mat_entry_srcptr(H, r, k, ctx), ctx);
        if (error) {
          gr_poly_clear(pg, ctx);
          gr_poly_clear(ph, ctx);
          gr_poly_clear(px, ctx);
          gr_poly_clear(p_tmp, ctx);
        }
      }
      _gr_poly_set_length(ph, m, ctx);

      error = gr_poly_reverse(ph, ph, m, ctx);
      if (error) {
        gr_poly_clear(pg, ctx);
        gr_poly_clear(ph, ctx);
        gr_poly_clear(px, ctx);
        gr_poly_clear(p_tmp, ctx);
      }
      error = gr_poly_mul(p_tmp, ph, px, ctx);
      if (error) {
        gr_poly_clear(pg, ctx);
        gr_poly_clear(ph, ctx);
        gr_poly_clear(px, ctx);
        gr_poly_clear(p_tmp, ctx);
      }

      error = gr_poly_shift_right(p_tmp, p_tmp, m - 1, ctx);
      if (error) {
        gr_poly_clear(pg, ctx);
        gr_poly_clear(ph, ctx);
        gr_poly_clear(px, ctx);
        gr_poly_clear(p_tmp, ctx);
      }
      _gr_poly_set_length(p_tmp, FLINT_MIN(gr_poly_length(p_tmp, ctx), m), ctx);

      error = gr_poly_mul(p_tmp, pg, p_tmp, ctx);
      if (error) {
        gr_poly_clear(pg, ctx);
        gr_poly_clear(ph, ctx);
        gr_poly_clear(px, ctx);
        gr_poly_clear(p_tmp, ctx);
      }

      if (gr_poly_length(p_tmp, ctx) > n) _gr_poly_set_length(p_tmp, n, ctx);

      for (slong i = 0; i < gr_poly_length(p_tmp, ctx); i++) {
        error = gr_add(gr_mat_entry_ptr(Res, i, j, ctx), gr_mat_entry_ptr(Res, i, j, ctx),
                       gr_poly_coeff_srcptr(p_tmp, i, ctx), ctx);
        if (error) {
          gr_poly_clear(pg, ctx);
          gr_poly_clear(ph, ctx);
          gr_poly_clear(px, ctx);
          gr_poly_clear(p_tmp, ctx);
        }
      }
    }
  }

  gr_poly_clear(pg, ctx);
  gr_poly_clear(ph, ctx);
  gr_poly_clear(px, ctx);
  gr_poly_clear(p_tmp, ctx);
  return error;
}
 \end{verbatim}

\subsubsection{Block Decomposition of the Displacement Operator}

To perform Strassen's inversion recursively, we must first split our $n \times n$ matrix $A$
into four sub-blocks of size $m \times m$ (where $m = n/2$). Let $A$ be:
$$A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$$

Similarly, we partition its displacement generators $G$ and $H$ (of size $n \times \alpha$)
into top and bottom halves of size $m \times \alpha$:
$$G = \begin{pmatrix} G_{top} \\ G_{bottom} \end{pmatrix}, \quad H = \begin{pmatrix} H_{top} \\ H_{bottom} \end{pmatrix}$$

As mentioned before, the $\phi_{+}$ displacement of $A$ is given by:
$$\phi_{+}(A) = A - Z_n A Z_n^T = G H^T$$

Following the displacement fomula,
If we divide $Z_n$ into four $m \times m$ blocks too, it needs the last puzzle piece to connect the shifting line from the top half
of the matrix to the bottom half. (In other words, we need a way to represent the part c of matrix A)

We build this using standard basis vectors $e$.
Let $e_0$ be a column vector with a $1$ at the top, and $e_{m-1}$ be a column vector with a $1$ at the bottom:
$$e_0 = \begin{pmatrix} 1 \\ 0 \\ \vdots \\ 0 \end{pmatrix}, \quad e_{m-1} = \begin{pmatrix} 0 \\ \vdots \\ 0 \\ 1 \end{pmatrix}$$

When we multiply the column $e_0$ by the row $e_{m-1}^T$, we get an $m \times m$ matrix of all zeros, with a single $1$ in the top-right corner.
This is our piece:
$$e_0 e_{m-1}^T = \begin{pmatrix} 1 \\ 0 \\ \vdots \\ 0 \end{pmatrix} \begin{pmatrix} 0 & \dots & 0 & 1 \end{pmatrix} = \begin{pmatrix} 0 & \dots & 0 & 1 \\ 0 & \dots & 0 & 0 \\ \vdots & \ddots & \vdots & \vdots \\ 0 & \dots & 0 & 0 \end{pmatrix}$$

Using this, we can write the full shift matrix $Z_n$ and its transpose $Z_n^T$ in block form:
$$Z_n = \begin{pmatrix} Z_m & 0 \\ e_0 e_{m-1}^T & Z_m \end{pmatrix}, \quad Z_n^T = \begin{pmatrix} Z_m^T & e_{m-1} e_0^T \\ 0 & Z_m^T \end{pmatrix}$$

First, we multiply $Z_n$ by $A$:
$$Z_n A = \begin{pmatrix} Z_m & 0 \\ e_0 e_{m-1}^T & Z_m \end{pmatrix} \begin{pmatrix} a & b \\ c & d \end{pmatrix} = \begin{pmatrix} Z_m a & Z_m b \\ e_0 e_{m-1}^T a + Z_m c & e_0 e_{m-1}^T b + Z_m d \end{pmatrix}$$

Next, $Z_n^T$:
$$(Z_n A) Z_n^T = \begin{pmatrix} Z_m a & Z_m b \\ e_0 e_{m-1}^T a + Z_m c & e_0 e_{m-1}^T b + Z_m d \end{pmatrix} \begin{pmatrix} Z_m^T & e_{m-1} e_0^T \\ 0 & Z_m^T \end{pmatrix}$$

Let's calculate the four resulting blocks:
\begin{itemize}
    \item \textbf{Top-Left:} $Z_m a Z_m^T$
    \item \textbf{Top-Right:} $Z_m a e_{m-1} e_0^T + Z_m b Z_m^T$
    \item \textbf{Bottom-Left:} $(e_0 e_{m-1}^T a + Z_m c) Z_m^T = e_0 e_{m-1}^T a Z_m^T + Z_m c Z_m^T$
    \item \textbf{Bottom-Right:} $(e_0 e_{m-1}^T a + Z_m c) e_{m-1} e_0^T + (e_0 e_{m-1}^T b + Z_m d) Z_m^T$
\end{itemize}

\subsubsection{Extraction of Block Generators}

By identifying the respective sub-blocks of the global displacement equation $\phi_{+}(A) = A - Z_n A Z_n^T = G H^T$, we can systematically extract the generators for each quadrant of $A$.

\paragraph{a:}
Equating the top-left blocks yields the direct displacement of $a$:
\begin{align*}
    a - Z_m a Z_m^T &= G_{top} H_{top}^T \\
    \phi_{+}(a) &= G_{top} H_{top}^T
\end{align*}
Since this block is unaffected, its generators are restored:
$$G_a = G_{top}, \quad H_a = H_{top}$$

\paragraph{b:}
Equating the top-right blocks to the initial equation. We isolate the terms belonging to $b$ on the left side:
\begin{align*}
    b - Z_m a e_{m-1} e_0^T - Z_m b Z_m^T &= G_{top} H_{bottom}^T \\
    b - Z_m b Z_m^T &= G_{top} H_{bottom}^T + Z_m a e_{m-1} e_0^T \\
    \phi_{+}(b) &= G_{top} H_{bottom}^T + (Z_m a e_{m-1}) e_0^T
\end{align*}
POINTER TO RAFAEL SUM GENERATOR:
$$G_b = \begin{bmatrix} G_{top} \mid Z_m a e_{m-1} \end{bmatrix}, \quad H_b = \begin{bmatrix} H_{bottom} \mid e_0 \end{bmatrix}$$

\paragraph{c:}
We follow the exact same process, but with the transpose property $(X Y)^T = Y^T X^T$ to group the vectors:
\begin{align*}
    c - e_0 e_{m-1}^T a Z_m^T - Z_m c Z_m^T &= G_{bottom} H_{top}^T \\
    c - Z_m c Z_m^T &= G_{bottom} H_{top}^T + e_0 e_{m-1}^T a Z_m^T \\
    \phi_{+}(c) &= G_{bottom} H_{top}^T + e_0 (Z_m a^T e_{m-1})^T
\end{align*}
THus, the generators for $c$ are formed by concatenation:
$$G_c = \begin{bmatrix} G_{bottom} \mid e_0 \end{bmatrix}, \quad H_c = \begin{bmatrix} H_{top} \mid Z_m a^T e_{m-1} \end{bmatrix}$$

\paragraph{d:}
The internal structure of the bottom-right block corresponds exactly to the top-left block evaluated on the bottom generators
$$d = \left( \sum_{k=1}^{\alpha} L(G_{bottom, k}) U(H_{bottom, k}) \right) + a$$
In terms of generators, matrix addition corresponds to horizontal concatenation. Given that $\phi_{+}(a)$ is generated by $G_{top}$ and $H_{top}$, we obtain:
$$G_d = \begin{bmatrix} G_{bottom} \mid G_{top} \end{bmatrix}, \quad H_d = \begin{bmatrix} H_{bottom} \mid H_{top} \end{bmatrix}$$
