# Elementary Operations on Structured Matrices

This is a uni project, we continued tho.

## Documentation

You can generate the HTML documentation locally in `docs` directory and running `make html`.

Open `_build/html/index.html` to view the documentation.

## Prerequisites

This project relies on the [FLINT (Fast Library for Number Theory)](https://github.com/flintlib/flint) library for its operations. Before building, you must have FLINT installed on your system.

> Installation for your specific OS can be found in the [official FLINT documentation](https://flintlib.org/doc/building.html). You can also refer to the `usage.html` file in this project's documentation.
